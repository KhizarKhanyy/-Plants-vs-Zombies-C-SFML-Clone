# 🌻 Plants vs Zombies Clone

A 2D Plants vs Zombies-inspired game developed in **C++** using the **SFML (Simple and Fast Multimedia Library)**.

This project was developed as the **Programming Fundamentals (PF) Semester Project** at **Air University Islamabad**.

---


# 📖 Project Overview

This project recreates the core gameplay mechanics of the classic **Plants vs Zombies** game.

The player must strategically place different plants to stop waves of zombies before they reach the house.

The project focuses on applying fundamental programming concepts while creating a complete graphical desktop game using SFML.

---
